# MLB Statistics: Web Scraping & Interactive Dashboard

## Project Overview
This project is a full-cycle data engineering and analysis tool designed to collect, process, and visualize Major League Baseball (MLB) hitting statistics. It demonstrates the ability to handle automated data collection, data cleaning with Python, and interactive web-based reporting.

## Key Features
* **Automated Web Scraping**: Uses **Selenium** to extract real-time batting averages from Baseball-Almanac.
* **Data Processing**: Cleans and transforms raw CSV data into structured formats using **Pandas**.
* **Interactive Visualization**: A dynamic dashboard built with **Streamlit** and **Altair**, allowing users to filter statistics by year, league, and batting average thresholds.
* **Data Integrity**: Includes a validation script (`clean.py`) to ensure data quality before visualization.

## Tech Stack
* **Language**: Python 3.13
* **Libraries**: Selenium, Pandas, Streamlit, Altair
* **Version Control**: Git/GitHub with a configured `.gitignore` for clean repository management.
